📊 PAPER HIGHLIGHTS

Title:
  Neural Architecture Search for Dynamic KV Cache Eviction Policies
  in Long-Context LLM Inference

Problem:
  KV cache quadratic memory bottleneck in long-context LLMs
  → Llama-3-8B needs 40GB for just 8K tokens

Solution:
  Neural Architecture Search (NAS) discovers task-specific cache allocations
  → Random sampling (200 configs) + Hill climbing + Bayesian optimization

Results:
  ✓ Multi-Doc QA: 36.14% (+0.54% vs uniform) @ budget 274
  ✓ Code: 58.26% (beats uniform@512 using 84% budget) @ budget 430
  ✓ Single-Doc QA: 33.51% (+0.54% at lower budget) @ budget 122
  ✓ All on Llama-3-8B & Mistral-7B (2 models)

Evaluation:
  ✓ 16 LongBench datasets (QA, code, summarization, retrieval)
  ✓ Needle-in-a-Haystack (1K-128K token contexts)
  ✓ RULER synthetic retrieval

Key Insight:
  Task-aware layer-wise budget allocation beats uniform allocation
  → Multi-Doc QA: allocate 45% to mid-layers (reasoning)
  → Code: uniform allocation (temporal context needed throughout)
  → Single-Doc QA: front-load budget (retrieval focus)
